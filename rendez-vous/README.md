# Mes Rendez-vous

Petite application (page web installable sur le téléphone) pour noter ses rendez-vous et recevoir un rappel avant.

## Ce qu'elle fait
- **Ajout rapide en écrivant normalement** : « demain 14h30 dentiste avec Dr Cohen », « lundi 9h réunion banque », « le 25/12 18h dîner famille », « 3 janvier 10h15 coiffeur ».
- Pour chaque rendez-vous : quoi, date, heure, durée, avec qui, où, catégorie (couleur), **notes** (ce qu'il faut apporter, préparer…).
- **Rappel** : à l'heure, 10 min, 30 min, 1 h, 2 h avant ou la veille — notification + sonnerie + fenêtre « Me rappeler dans 10 min ».
- Vue « À venir » (classée par jour), la semaine en haut avec des points de couleur, « Passés », recherche.
- Résumé du jour : combien de rendez-vous aujourd'hui et le prochain (« dans 25 min »).
- Cocher un rendez-vous comme fait.
- **📅 Agenda du téléphone** : met le rendez-vous (avec son rappel) dans l'agenda du téléphone.
- Sauvegarder / restaurer ses rendez-vous dans un fichier.
- Fonctionne sans internet ; les données restent dans l'appareil.

## Important pour les rappels
Une page web ne peut sonner que si elle est ouverte (ou en arrière-plan récent).
Pour être sûr d'être prévenu même téléphone verrouillé, ouvrez le rendez-vous et touchez **📅 Agenda du téléphone** :
le rappel est alors aussi géré par l'agenda du téléphone.

## L'installer sur le téléphone
1. Ouvrir la page dans le navigateur (Chrome sur Android, Safari sur iPhone).
2. Android : menu ⋮ › « Ajouter à l'écran d'accueil ». iPhone : bouton Partager › « Sur l'écran d'accueil ».
3. Toucher « Activer les rappels » et accepter les notifications.
